# Axstack feature map

Run [Launch and Doctor](../SKILL.md) before these offline paths. Each file names
its source entry points, prerequisites, drive commands and observable proof.

| User feature | Recipe | Evidence |
| --- | --- | --- |
| Install skills and inspect host setup | [Install/check/version](install.md) | Owned files, repeat install, legacy retirement/retry, stable T3 prerequisite and read-only capability gaps |
| Recommend a worker from supplied fleet facts | [Selector/CLI/binding](dispatch.md#fleet-recommendations-and-destination-binding-c1) | Ordered stages, eligibility, config/catalog digests, destination readback, spread and clock/precision |
| Collect bounded fleet telemetry | [Sampler](telemetry.md) | Linux arithmetic, concurrent batch, deadlines/cancellation, collector clock, replayable C1 integration |
| Route local non-repository Research/Explain/Publish | [Artifact scope](dispatch.md#explicit-local-non-repository-articles) | Shared native task, exact role/settings/ownership, SHA-256 receipts and engineering exclusions |
| Resolve saved models and prepare dispatch | [Model/dispatch plans](dispatch.md) | Resolved model, bound instance, MATCH readback |
| Start run records and assess a candidate | [Records/reports](reports.md) | Owned fixture record, shape totals, pinned static readiness |
| Inspect distributable contents | [Package contents](package.md) | Full pack listing, excluded repo skill, no archive write |
| Workflow contracts | [Workflow contracts](workflows.md) | Saved-default fixture CLI/hub, role titles and semantic source contracts |
| UI improvement and Explain/Publish delivery | [UI workflows/delivery](ui.md) | UI discovery/iteration semantic checks, private audience authority and reviewer/verifier delivery drives |
| Build an explicit Anatomy figure | [Anatomy source/theme](anatomy.md) | Source inventory, wrapper/scratch build and delegated frame-theme/compositing drive |

Gotchas: scratch must be outside HOME; installation uses a private temporary HOME
and provisions no external tools. Fixture catalogs prove no live model availability.
Static readiness needs an evidence-owned separate Git directory because of
its output guard. Read-only offline forge observations remain unknown.

Uncovered surfaces: live fleet sampling/links/dispatch and remote-author pilot gates;
use the shipped [bounded live procedure](../../../../skills/axstack/references/fleet-verification.md)
under separately recorded C3/C6 authority. Offline bindings cannot authenticate
native evidence or enable routing. Other uncovered surfaces: live T3 MCP launches, driver gating previews, live T3 frame delivery, external Notion/Linear, provider authentication,
scheduled work, npm staging approval and release installation across hosts.
These require their own authorized isolated verification; never infer them
from this CLI recipe. The install feature maps retirement/retry fixtures; workflow and Anatomy
features map reviewer-owned source drives and delegated browser checks.
Simulated frames do not prove live T3 behavior, and author logs never replace
the reviewer/verifier local drive at the final head.
