# STE-inspired writing

STE means Simplified Technical English.
This reference borrows clarity rules from STE.

Follow these rules only for new or materially revised user-facing output.
User-facing output includes reports, PR bodies, briefs, read-backs, and packaged guidance.
Do not rewrite existing prose for style.
Keep exact identifiers unchanged.
Keep quotes unchanged.
Keep safety contracts unchanged.
Keep prompt-byte contracts unchanged.

Give each sentence one instruction.
Keep sentences short.
Write in active voice.
If a step has a condition, state the condition before the step.
Define technical terms before their first use.
Use one name consistently for each term.
Use words instead of slashes for "and" or "or".
