# Source checklist

1. Write the bounded question and its exclusions first.
2. Fetch each primary source directly; cite what was actually inspected.
3. Date and pin time-sensitive claims: version, revision, access date.
4. Tag each material claim: verified, inference, or unverified.
5. List what was not checked under limitations; never fill gaps silently.
6. Save the source-linked Markdown artifact; stop — no spec, tickets, or
   implementation follow for a research-only run.
