# Round-3 step-back

An unavailable Astra or Opus step-back seat counts as no agreement and falls
to the user with the advised step-back card. Verified Muse absence does not
count as no agreement; a launched Muse adviser remains outstanding.
Follow [Advised holds](../../axstack/references/contracts.md#advised-holds) for
seat attempts, waits, gaps and cards, including the round-4 card's delta-only adviser reuse.

Each adviser independently gets the open findings and the author's replies.
Each adviser independently gets the per-round deltas.
Each adviser independently gets blame showing the round in which each flagged line first appeared.
Each adviser independently gets the approved scope, sketch and approach.

Send one advised repair brief to the same author for the extra round only when all conditions below hold:

- The driver accepts the path.
- Every adviser that ran recommends the same path; pending Muse advice blocks
  the extra round. A split, including AGREE-WITH-CHANGES, goes to the card.
- The path stays inside the approved scope.
  The path must not break a sketch `Binding` line.
- No independent hold applies.

The extra round requires fresh independent reviewer and diligence receipts, with a fresh session of the same mapped reviewer role.
Do not add an extra reviewer.
Advisers must never lower a rating or clear a finding.
Advisers can propose `Pre-existing` with evidence, which the extra-round reviewer validates under
[review's Pre-existing rules](../../axstack-review/SKILL.md#finding-severity).

When any condition fails, record `held` and fall to the user with the advised step-back card.
Failed conditions include an adviser split, an unavailable Astra or Opus seat, the driver rejecting the agreed path,
or the only path leaving approved scope or breaking a `Binding` line.
A scope change follows the existing material-revision route.
An independent hold keeps its own card and rules, with received step-back advice attached as context.
After an independent hold clears, recheck all extra-round conditions and reuse unchanged advice.
